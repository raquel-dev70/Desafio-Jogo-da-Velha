# Desafio Jogo da Velha

Projeto desenvolvido para fins acadêmicos abrangendo conceitos de HTML e CSS (como placeholder, label, board, margin) e aprimorado com o uso do Gemini para a lógica de JavaScript, ajudando na prática de desenvolvimento web.

## 🚀 Tecnologias Utilizadas
* HTML5
* CSS3 (Flexbox e Grid)
* JavaScript
